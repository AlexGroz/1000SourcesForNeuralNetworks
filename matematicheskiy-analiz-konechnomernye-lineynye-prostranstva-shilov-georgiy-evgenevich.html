§ 1.1 Числовые поля

1.1. Как и бо́льшая часть математики, линейная алгебра использует числовые системы (числовые поля). Числовым полем называют всякую совокупность K объектов, называемых числами,в которой можно производить с этими объектами четыре арифметических действия. Перечислим необходимые сведения об этих действиях (аксиомы поля).
а. Каждой паре чисел α и β отвечает число α+β, называемое суммой чисел α и β, причем
1) α+β = β+α для любых α и β из K (переместительность, или коммутативность сложения).
2) (α+β)+γ = (α+β)+γ для любых α, β, γ из K (сочетатильность, или ассоциативность сложения).
3) Существует число 0 (нуль) такое, что 0+α = α 0+α=α для любого α из K;
4) Для любого α из K существует число β из K такое, что α+β=0 (противоположный элемент).
Разрешимость уравнения α+β = 0 при любом α позволяет ввести операцию вычитания: разность α−β по определению есть сумма числа α и решения γ уравнени β+γ = 0.
б. Каждой паре чисел α и β отвечает число α⋅β (αβ), называемое произведением чисел α и β, причем
5) αβ=βα для любых α и β из K (коммутативность умножения);
6) (αβ)γ=α(βγ) для любых α,β,γ из K (ассоциативность умножения);
7) Существует число 1(≠0) такое, что 1⋅α=α для любого числа α из K;
8) Для любого α≠0 существует число γ из K такое, что αγ=1 (обратный элемент).
